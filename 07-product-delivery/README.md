# Juno Product-Delivery Pack

This folder turns the approved Juno opportunity into the product artifacts needed from discovery through post-launch learning.

| Stage | Artifact | Decision it supports |
|---|---|---|
| Discover | [`one-page-prd.md`](./one-page-prd.md) | Is the problem valuable and bounded? |
| Decide | [`roadmap.md`](./roadmap.md) | What path and sequence fit the uncertainty? |
| Design | [`prototype-brief.md`](./prototype-brief.md) | What must the prototype prove? |
| Define | [`epics-and-stories.md`](./epics-and-stories.md) | What should the team build? |
| Validate | [`uat-plan.md`](./uat-plan.md) | Is the experience useful, correct, and safe? |
| Launch | [`launch-pack.md`](./launch-pack.md) | How will we position, communicate, and learn? |
| Release | [`rollout-checklist.md`](./rollout-checklist.md) | Are product and operations ready? |
| Adopt | [`user-manual.md`](./user-manual.md) | How does a PM use Juno safely? |
| Learn | [`post-launch-review.md`](./post-launch-review.md) | Did the release improve outcomes? |

The full system PRD remains in [`../03-rag-prd/prd.md`](../03-rag-prd/prd.md). This pack intentionally does not invent customer proof: prototype data is synthetic, and open validation questions are labelled.
