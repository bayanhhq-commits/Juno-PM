# Lovable Prototype · Juno

> Module 1 · Prompting. The clickable Lovable prototype that brings the system prompt to life.

## Prototype link

[Open the Juno PM prototype](https://rocketship-prd-builder.lovable.app/)

_____

## What it demonstrates

The prototype demonstrates one end-to-end workflow: a Product Manager pastes messy raw user feedback, clicks **Process Transcript**, and Juno transforms it into prioritised, sentiment-tagged insights and a structured Opportunity Brief in PRD format.

_____

## Debrief

- **What worked:** The three-column layout makes the transformation from raw evidence to structured insights to a draft PRD easy to understand. The dark interface, single accent colour, clear hierarchy, and visible processing action make the workflow feel focused and professional.
- **What broke / felt like a toy:** The processing is still a prototype simulation rather than a live AI workflow. The generated insights and PRD are not yet traceable to exact source quotes, and users cannot edit, validate, or export the draft.
- **What I'd change next pass:** Connect the workflow to a real model, add source citations for every insight, introduce empty and error states, and make the PRD editable with export to tools such as Notion or Jira.
